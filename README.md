# Увядание памяти
Увядание памяти (Memory Decay Synthesizer)
«Увядание памяти» — ностальгический эмбиент-веб-инструмент для исполнения короткого музыкального этюда. В нём взаимодействуют два голоса: хрустальная высокая мелодия в левом канале и тёплый гармонический подголосок в правом. Исполнитель управляет общим состоянием деградации звука и пространства через единый макро-регулятор увядания.


Концепция
Инструмент предлагает управлять музыкальным пространством и эмоциональным состоянием памяти через небольшое число понятных действий: запустить мелодию кликом по заголовку, настроить тембры, управлять огибающей и плавно погружать композицию в звуковой хаос с помощью винилового ползунка.

Название «Увядание памяти» связывает деградацию звука с синхронным изменением цвета интерфейса: по мере старения нежно-голубая палитра плавно сменяется на холодный пепельно-серый тон. Визуальная основа выполнена в эстетике тактильного софт-неоморфизма в духе студийного оборудования Braun и Teenage Engineering.

Музыкальный эскиз
Основа композиции — меланхоличная гармоническая тема в до-миноре. Начальный темп — 88 BPM, размер — 4/4. Партии записаны на сетке из восьми шагов на такт; весь цикл содержит 64 шага.

Голоса воспроизводят разные тембры (синусоида, пленочные и язычковые волны, орган, аккордовые и призрачные структуры), проходящие через независимые цепочки пространственной и частотной обработки.

Музыкальная последовательность подготовлена по выбранному автором направлению. Представленные музыкальные референсы использовались для обсуждения настроения и характера звучания; их аудиозаписи не включены в проект.

Возможности прототипа
Общие запуск (по клику на главный заголовок), остановка, темп и панорама (STEREO L/R).

Независимые переключатели тембров для левого и правого каналов.

Пятиполосная огибающая (ADSR + VEL) для настройки атаки и затухания нот.

Главный ползунок «Увядание» в стиле старой виниловой пластинки: синхронно срезает частоты, добавляет виниловую пыль, детонацию и перекрашивает интерфейс.

Двухканальные цепочки эффектов: компрессор, фильтр, фленджер, виниловый шум (левый канал) / дилей, хорус, Lo-Fi деградация, лимитер (правый канал).

Интерактивная подсветка нот мини-клавиатуры (C4–C5) и индикация шагов секвенсора.

Адаптивная компоновка и строгая трёхколонная сетка интерфейса.

Регуляторы работают до запуска и во время исполнения. Управление позволяет менять тембры, характер звучания и степень увядания на лету.


Устройство инструмента
Интерфейс написан на HTML, CSS и JavaScript. Звук создаётся через Web Audio API в реальном времени. Vite используется для локального запуска и сборки. React в текущей версии не используется.

У каждого голоса своя цепочка обработки:

Левый канал: Oscillator L
→ Compressor
→ Filter (Cutoff)
→ Flanger
→ Vinyl Dust
→ выход левого канала.

Правый канал: Oscillator R
→ Delay
→ Chorus
→ Lo-Fi Crush
→ Limiter
→ выход правого канала.

Каналы имеют независимое панорамирование. Обе партии синхронизированы общим аудио-транспортом.

Файл	Назначение
index.html	Каркас страницы, неоморфная сетка, панели каналов и центральное ядро
src/audio.js	Аудиограф на Web Audio API, осцилляторы, цепочки эффектов и логика увядания
src/main.js	Связь элементов управления интерфейса, кнопок, фейдеров и звукового движка
src/style.css	Визуальное оформление, мягкие тени неоморфизма, динамические цветовые токены и адаптивность
В интерфейсе повторяются блоки регуляторов, поворотные ручки (Rotary Knobs), вертикальные фейдеры и светодиодные индикаторы. CSS-классы обозначают назначение элемента (chassis, core-section, fx-block) или его состояние (is-active).
